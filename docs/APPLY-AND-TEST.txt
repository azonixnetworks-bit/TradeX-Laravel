TradeX OS - API-12 PayPal Product Purchase Plugin Integration
=============================================================

Target branch:
  feature/api-12-paypal-plugin-ph

This package is designed for the existing TradeX API-12 architecture.
It DOES NOT create a duplicate Order model/table and does NOT replace
PaymentOrder, Payment, UserEntitlement, affiliate settlement, or webhook flow.

Already completed on your local branch:
  composer require "srmklive/paypal:^3.1" -W
  php artisan vendor:publish --provider="Srmklive\PayPal\Providers\PayPalServiceProvider"

IMPORTANT:
  Keep your existing local composer.json + composer.lock changes from the
  successful package installation. This ZIP intentionally does not overwrite
  composer.lock.

LIVE/SANDBOX E2E FLOW
---------------------
Existing API-12 endpoints remain unchanged:

  POST /api/v1/payments/paypal/orders
  POST /api/v1/payments/paypal/orders/{uuid}/capture

Create order response should include:
  product_code = EDUCATION_PREMIUM
  amount = USD 79.00
  status = AWAITING_USER_ACTION
  approval_url = PayPal checkout URL

The PayPal order now carries the course as a DIGITAL_GOODS line item:
  Name: TradeX Education Premium
  SKU: EDUCATION_PREMIUM
  Quantity: 1
  Amount: USD 79.00
  Shipping: NO_SHIPPING

After buyer approval, call the existing capture endpoint.
A COMPLETED capture is settled by the existing TradeX settlement flow:
  PaymentOrder -> CLEARED
  Payment -> CLEARED
  User -> PREMIUM
  UserEntitlement -> ACTIVE
  Affiliate processing -> existing API-12 behavior

PAYPAL MERCHANT RESTRICTION NOTE
--------------------------------
This code cannot bypass PayPal merchant/account restrictions.
If PayPal checkout returns PAYEE_ACCOUNT_RESTRICTED or
PAYEE_ACCOUNT_LOCKED_OR_CLOSED, the PayPal merchant account must be resolved
with PayPal. Do not change TradeX settlement logic to work around that error.
