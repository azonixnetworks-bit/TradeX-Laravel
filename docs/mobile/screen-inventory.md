# TradeX Mobile Screen Inventory

## App entry and identity
Splash, preferred language, login, registration, email verification, WhatsApp verification, TOTP setup/challenge, forgot/reset password, session/device-blocked states.

## Home
Home dashboard, notification entry, Our Channel, Copy Trade entry, subscription/access state, and **Screener — COMING SOON** card. The rejected legacy blue dashboard concept is not part of this inventory.

## Learn
Learn home with `All | Forex | Crypto | Stocks | Deriv`, course details, module list, lesson/video player, progress, assignment details + WhatsApp action, certificate/completion states.

## Trade Ideas
Trade Ideas home, Long Term Trade Idea, Daily Trade Idea, market filtering for Forex/Crypto/Deriv/Stocks, Stocks region drill-down (`CSE-LK | India | International`), idea detail and approved share actions.

## Affiliate
Affiliate home, permanent general referral link/code, direct qualified sales, stage/progress, earnings, payout request/status/history. API wiring is blocked until a mobile affiliate contract is frozen.

## Profile
Profile home, personal/contact details, password/security/TOTP, trusted devices, payout/payment account details, broker accounts, notification preferences, logout.

## Payments and entitlement
Lifetime education purchase (`USD 79`), available configured payment method selection, payment status, Payment History, Transaction Detail and Invoice. Client must use server-configured/approved payment contracts rather than hardcoding processor assumptions.

## Copy Trade
Broker onboarding, partner/IB account-open action, broker/account submission, PENDING review, VERIFIED state, broker account list/detail, eligibility/activation/billing states. Server remains authoritative for verification and activation gates.

## Notifications / deep links
Notification center, notification detail/deep-link routing, read state once an API is frozen.

## Release/system states
Offline/retry, maintenance/update-required, unauthorized/session-expired, premium-required, device-limit, generic safe error, legal/risk disclosure surfaces.
